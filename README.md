# Habitos Frontend

Frontend de la aplicación de gestión de hábitos basada en el libro *Hábitos Atómicos* de James Clear.  
Desarrollada con **Next.js**, **React** y **Redux Toolkit**, y con  datos desde un backend **Express.js** conectado a **MongoDB**.

---

## Tecnologías

- Next.js, React
- Redux Toolkit
- Fetch API
- Node.js


## Instalación de dependencias

En la terminal ejecutar el comando
npm install

## Ejecutar la aplicacion

en la terminal con el comando 
npm run dev

La app correrá por defecto en http://localhost:3001

Asegúrate de que el backend esté corriendo en http://localhost:3000
